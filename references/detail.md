## 附录

### 附录 A：核心著作概要

**《论生命之短暂》（De Brevitate Vitae, 约49年）**

写给岳父庞利努斯，论述时间的正确使用。核心论点：
- 人生不是太短，而是被浪费了太多
- 大多数人活着像是永远不会死，死时像是从没活过
- 忙碌不等于充实——很多人"忙碌地无所事事"
- 只有哲学家才真正"活着"——因为他们审慎地使用每一刻

**《道德书简》（Epistulae Morales ad Lucilium, 62-65年）**

124封写给年轻朋友卢基里乌斯的信，涵盖：
- 时间管理（第1封：时间是唯一不可回收的资源）
- 阅读方法（第2封：深读少数几本书，不要贪多）
- 旅行的意义（第28封：换地方不能换心态）
- 友谊的价值（第3、6、9封）
- 死亡的准备（第26、77封）
- 简朴生活（第18封：定期练习贫穷）

**《论愤怒》（De Ira, 约41年）**

三卷本，系统讨论愤怒的本质和对策：
- 愤怒是"短暂的疯狂"——它让人失去理性
- 愤怒的触发：印象 → 判断 → 情绪 → 行动
- 对策：延迟（不要在愤怒中行动）、预想（提前预期他人的缺点）、宽容（他人的错误源于无知）

**《论心灵的安宁》（De Tranquillitate Animi）**

写给朋友塞雷努斯，讨论如何获得内心平静：
- 心灵不安的根源：在参与与退隐之间摇摆不定
- 解决之道：找到适合自己的参与程度；在退隐中保持活跃的精神生活
- 实用建议：简化生活、减少社交、阅读、写作

**《论恩惠》（De Beneficiis, 约56-64年）**

七卷本，讨论人际间的馈赠与感恩：
- 恩惠是社会的纽带——没有它，社会就会瓦解
- 给予和接受恩惠都是美德
- 忘恩负义是最大的恶行之一

### 附录 B：塞涅卡的生平要事

| 时间 | 事件 |
|------|------|
| 约前4年 | 出生于西班牙科尔多瓦 |
| 约14年 | 随家人迁居罗马，开始接受教育 |
| 约31年 | 开始政治生涯，进入元老院 |
| 41年 | 被克劳狄乌斯流放至科西嘉岛（罪名：与皇帝侄女通奸，可能是政治迫害）|
| 49年 | 阿格里皮娜召回塞涅卡，任命为尼禄的老师 |
| 54年 | 尼禄即位，塞涅卡成为首席顾问——"黄金五年"开始 |
| 59年 | 尼禄杀母阿格里皮娜——塞涅卡撰写辩护词（争议最大的时刻）|
| 62年 | 塞涅卡请求退休，尼禄拒绝但逐渐疏远 |
| 62-65年 | 半退隐状态，写作最密集的时期（《道德书简》等）|
| 65年 | 皮索阴谋事发，尼禄赐塞涅卡自杀——他平静地打开血管而死 |
